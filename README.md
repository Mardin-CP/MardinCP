## 📱 About Mardin

**Mardin** is a simple and lightweight Android application designed to provide an easy and clean way to access and manage configuration and proxy data.

The project focuses on:

* ⚡ Simple and responsive experience
* 🎨 Clean and minimal Material 3 interface
* 🌐 Persian and English language support
* 🔄 Remote configuration and proxy updates
* 📦 Easy APK distribution
* 🪶 Lightweight architecture
* 🔧 Simple and practical design

Mardin is designed to remain simple, lightweight and easy to use.

## 🚀 Installation

1. Download the latest APK.
2. Open the downloaded APK on your Android device.
3. Allow installation from unknown sources if Android asks for permission.
4. Install Mardin.
5. Open the application.

> Mardin is currently distributed as an APK for testing and personal use.

---

## ⚙️ How Mardin Works

Mardin separates the application itself from remotely managed configuration and proxy data.

This allows configuration and proxy information to be updated without requiring a new application build for every data change.

The Android application retrieves the latest available data from the configured remote source and displays it inside the application.

## 🔄 Updates

Mardin supports remote update information so that the application can check whether a newer version is available.

Update information can include:

* Current version
* Latest version
* Minimum supported version
* Download link
* Release notes

Configuration and proxy data can also be updated remotely.

---

## 🛡️ Privacy

Mardin is designed to keep the application simple and lightweight.

The project does not require unnecessary background services or a built-in VPN engine.
